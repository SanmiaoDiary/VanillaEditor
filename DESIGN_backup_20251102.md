# VanillaEditor 设计文档
## 1. 项目简介
VanillaEditor 是一个支持离线编辑、多设备同步、版本管理的文本编辑器。
## 2. 项目结构
项目使用python 和flask开发分成前端和后端两部分
前端：用户界面
后端：提供接口，处理用户请求
### 1. 前端
html5 js css 使用bootstrap5 框架
### 2. 后端
使用flask 框架
#### 1. 功能
1. 文本编辑
2. md预览
3. 项目管理
4. 工作区管理
5. 版本管理（git）
6. 多设备同步

## 4. 功能设计
### 1. 文件资源管理器
1. 打开工作区的时候在这个文件夹里面创建一个名为.ve的文件夹用来保存当前ve工作区的状态（打开的工作区、标签页（文件）等等），并在下次用户登录时恢复原状
2. 打开工作区不要在/data目录里面新建一个文件夹来存放这个工作区里面的内容，就在用户选择的那个目录下就好了，其他东西都不要乱动
3. 打开工作区的时候一定要记得是在服务器上打开而不是在用户的设备（客户端）上打开！
4. 所有的工作区可以保存在/data文件夹下的/all_workspaces文件夹里面，每个工作区都是一个json文件里面保存了这个工作区的目录、名字
5. VE找到这个工作区json之后就去对应的路径里面查找.ve文件夹，从里面读取工作区的状态然后还原在前端上
### 2. 版本管理器（Git）
1. 依赖git才能运行，但是ve没有git本身也可以正常运行，只是这个功能不可用

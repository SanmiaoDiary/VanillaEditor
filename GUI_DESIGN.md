# VanillaEditor GUI 设计

> 界面风格参考 VSCode，但针对 Markdown 编辑场景做了简化，Git 操作界面更加直观友好。

---

## 1. Menu Bar（菜单栏）

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ 🌿 VanillaEditor    文件  编辑  视图  Git  帮助    [📄 main.py] [×]          │
└───────────────────────────────────────────────────────────────────────────────┘
```

左侧固定 Logo + 应用名，右侧显示当前打开文件的标签（可关闭）。

### 菜单下拉项

**文件**
- 新建文件 … `Ctrl+N`
- 新建文件夹 … `Ctrl+Shift+N`
- 打开文件夹 … `Ctrl+O`
- 保存 `Ctrl+S`
- 全部保存 `Ctrl+K S`
- 退出

**编辑**
- 撤销 `Ctrl+Z`
- 重做 `Ctrl+Y`
- 剪切 `Ctrl+X`
- 复制 `Ctrl+C`
- 粘贴 `Ctrl+V`
- 查找 `Ctrl+F`
- 替换 `Ctrl+H`
- 格式化文档 `Shift+Alt+F`

**视图**
- 切换侧边栏 `Ctrl+B`
- 切换 Git 面板 `Ctrl+Shift+G`
- 分割编辑器 `Ctrl+\`
- 切换主题
- 放大 / 缩小字体

**Git**
- 拉取 `Ctrl+Shift+P`
- 提交所有更改
- 推送
- 查看历史
- 管理分支

**帮助**
- 快捷键参考
- 关于

- 当前激活项高亮（蓝色左侧竖条）

## 5. Git 面板（📦）

简洁、线性操作流，没有 VSCode 的改动区/暂存区分栏，一个流程走到底：

```
┌─────────────────────────────────────────────────────────┐
│ 📦 版本管理     Git                                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [ 🔄 拉取 ]                                            │
│                                                         │
│  [ ⬆ 提交到暂存区 ]                                     │
│                                                         │
│  提交信息：                                              │
│  ┌───────────────────────────────────────────────────┐  │
│  │                                                   │  │
│  │  update main.py and config.yaml                   │  │
│  │                                                   │  │
│  │                                                   │  │  ← 自动生成的默认消息，可自由编辑
│  │                                                   │  │
│  └───────────────────────────────────────────────────┘  │
│                                                         │
│  [ 提交 ]    [ 推送 ]                                    │
│                                                         │
│  同步到  [ 所有设备 ▼ ]    [ 同步 ]                      │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ 最近提交（可折叠）                                       │
│ ○  update main.py        main  ·  2分钟前              │
│ ○  add readme            main  ·  1小时前              │
│ ○  init project          main  ·  昨天 20:15           │
└─────────────────────────────────────────────────────────┘
```

### 各控件说明

| 控件 | 功能 |
|------|------|
| **拉取** | 执行 `git pull`，从配置的远端拉取最新提交并自动合并 |
| **提交到暂存区** | 将所有未暂存的改动执行 `git add -A`，移到暂存区 |
| **提交信息** | 大文本框，底部状态栏会自动填入默认消息（如 `update: main.py, config.yaml`），用户可覆盖 |
| **提交** | 执行 `git commit`，将暂存区内容提交本地仓库 |
| **推送** | 执行 `git push`，推送本地提交到配置的远端 |
| **同步到** | 下拉选择目标设备（显示所有已配置的远端 + "所有设备"），点击「同步」后执行对应的 push + pull |
| **最近提交** | 可折叠的历史列表，点击某条记录可查看该版本的完整 diff |

### 流程说明

```
① 拉取  →  ② 提交到暂存区  →  ③ 填写/确认提交信息  →  ④ 提交  →  ⑤ 推送
                                                                              ↓
⑥ 同步到 ←───────────────────────────────────────────────────────────────────┘
（可选一步完成 push + pull）
```

按钮状态规则：
- **拉取**：始终可用
- **提交到暂存区**：有未暂存文件时高亮，无变动时置灰
- **提交**：有暂存内容时高亮，否则置灰
- **推送**：有未推送提交时高亮
- **同步**：有可用远端时高亮

## 6. Editor 区域

### 5.1 普通编辑器

```
┌─────────────────────────────────────────────────────────────────┐
│ 📄 main.py                    Ctrl+Z 撤销    Ctrl+Y 重做  ⋯    │  ← Tab bar
├─────────────────────────────────────────────────────────────────┤
│  1 │ #!/usr/bin/env python3                                   │  ← Line numbers
│  2 │                                                           │
│  3 │ def hello(name: str) -> str:                             │
│  4 │     """Greet someone."""                                  │
│  5 │     return f"Hello, {name}!"                              │
│  6 │                                                           │
│  7 │ if __name__ == "__main__":                                │
│  8 │     print(hello("World"))                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 Markdown 编辑器（双栏）

```
┌─────────────────────────────────────────────────────────────────┐
│ 📄 readme.md              [Source] [Preview] [Split]           │
├──────────────────────┬──────────────────────────────────────────┤
│ # Hello World        │  # Hello World                           │
│                      │                                          │
│ ## Getting Started   │  ## Getting Started                      │
│                      │                                          │
│ ```python           │  <h2>Getting Started</h2>                 │
│ def hello():         │                                          │
│     pass             │  <pre><code class="language-python">     │
│ ```                  │  def hello():                            │
│                      │      pass                                │
│ > 这是一段引用       │  </code></pre>                            │
│                      │                                          │
│ - 列表项 1           │  <ul>                                    │
│ - 列表项 2           │    <li>列表项 1</li>                      │
│                      │    <li>列表项 2</li>                      │
│                      │  </ul>                                   │
│                      │                                          │
│                      │  > 这是一段引用                          │
└──────────────────────┴──────────────────────────────────────────┘
```

- **Source**：只看 Markdown 源码
- **Preview**：只看渲染结果
- **Split**：左右分栏（默认）

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+Shift+G` | 打开 Git 面板 |
| `Ctrl+S` | 提交所有改动（Git 面板聚焦时） |
| `Ctrl+Shift+F` | 全局搜索 |
| `Ctrl+B` | 切换侧边栏 |
| `Ctrl+`` ` | 切换终端/面板 |
| `F1` | 打开命令面板 |
| `Esc` | 关闭弹窗/回到编辑器 |
